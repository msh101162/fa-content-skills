# مارکتینگ فارسی — مهارت عامل

## بخش سئو (fa-marketing-seo)

### مشکل واقعی سئوی فارسی: واریانت املایی

همان کیورد روی وب فارسی چند پوست دارد: «خرید کتاب» / «خریدكتاب» (ک عربی)
/ «کتاب‌ها» (ZWNJ). موتور جست‌وجو این‌ها را یکسان نمی‌بیند. ابزار:

```python
from marketing import keyword_variants

v = keyword_variants("خرید کتاب")   # همه واریانت‌ها را در بریف پخش کن
```

### چک‌لیست on-page با عرض رندر RTL

```python
from marketing import audit_page

a = audit_page(title_tag, meta_description, h1, body, keyword="خرید کتاب")
```

- تیتر تگ: بازه ۴۵–۶۰ نویسه، سقف ۶۵؛ ولی برش SERP با **عرض رندر** است —
  فارسی باریک‌تر است، پس مدل عرض RTL را هم چک می‌کند (~۶۲۰px).
- توضیحات متا ۱۴۰–۱۶۰ نویسه؛ کیورد در ۱۲۰ نویسه‌ی اول.
- ZWNJ در H1/متا **حذف نمی‌شود** — حذفش مرز کلمه را می‌شکند و همان
  کیورد را می‌خشکاند.
- چگالی کیورد ۰.۵–۲.۵٪؛ بیشترش استافینگ است نه سئو.

### بریف محتوا (اسکلت)

ساختار بریف در `marketing.seo.BRIEF_SKELETON`: کیورد اصلی + واریانت‌ها،
قصد جست‌وجو (از SERP فعلی استنتاج کن، از حدس نه)، رئوس H2/H3، نهادهای
فارسی، ۳ لینک داخلی با انکر توصیفی (نه «اینجا کلیک کنید»).

## بخش کپی‌رایتینگ (fa-marketing-copy)

### فریم‌ورک‌ها

```python
from marketing import framework

f = framework("PAS")   # یا AIDA / BAB / 4U / FAB
```

هر فریم‌ورک: `beats` فارسی اصطلاح‌محور + میدان `guard` (خرابی مشهورش).
**قالب را ترجمه نکن، ساختار را ببر** — «درد» در PAS فارسی با عدد گفته
می‌شود، نه با صفت.

### ویرایش سریع

```python
from marketing import quick_edit, EDIT_CHECKLIST

rep = quick_edit(draft)
```

- صفت‌های توخالی («بی‌نظیر»، «فوق‌العاده») → عدد یا جزئیات.
- فعل ضعیف → فعل قوی؛ جمله‌ی ۲۵+ کلمه‌ای → دو جمله.
- چک‌لیست کامل: «عدد به‌جای صفت، فعل به‌جای اسم، جمله کوتاه‌تر از آنچه می‌ترسی.»

## قواعد ضدجعل و slop

- عدد/نام/نتیجه از کاربر؛ نداشتی؟ `{{عدد شما}}` خالی + پرچم.
- واژه‌نامه‌ی slop فارسی (`core.slop_lexicon`) را قبل از تحویل اجرا کن —
  به‌خصوص «باز کردن قفل»، «قدرت‌بخشی»، «نه فقط … بلکه …» و سه‌صفت پشت‌سرهم.
- ادعای سئو که عدد یا منبع ندارد یا اثبات می‌شود یا حذف.

## خلاف‌ها (رد می‌شود)

- کیورد استافینگ با پاراگراف ربات‌وار؛ «هشت کلیدواژه در جمله اول».
- ترجمه تحت‌اللفظی فریم‌ورک («قدرت‌بخشی به کسب‌وکار شما»).
- انکر لینک داخلی «اینجا» یا «کلیک کنید».
