# اینستاگرام فارسی — مهارت عامل

> «این مهارت‌ها می‌نویسند. تو پست می‌کنی.» هیچ‌چیز بدون تأیید تو منتشر نمی‌شود؛
> انتشار خودکار نقض شرایط اینستاگرام است و اکانت را محدود می‌کند.

## پیش‌نیازها

هیچ. همه ابزارها stdlib پایتون‌اند، آفلاین اجرا می‌شوند و کلید ندارند.
هر مهارت بدون هیچ تنظیمی خروجی مفید می‌دهد (پلکان تنزل: ابزار → راهنمای دستی).

## قواعد سراسری صدا

یک قاعده واحد در ریشه: `core/` ابزار اندازه‌گیری است، `instagram/` قالب است.
قاعده طلایی: **مدل تصمیم می‌گیرد؛ اسکریپت اندازه می‌گیرد.** طول، برش فید و
چگالی slop را چشمی حدس نزن — ابزار را اجرا کن:

```python
from instagram import lint, score_hook, humanize, plan_carousel, audit_deck
```

## کارویژه‌ها

### ۱. کپشن (fa-instagram-caption)

```python
from instagram import lint, preview_fold, render

rep = lint(caption, keywords=["دوربین فیلمبرداری"])   # ۹ چک فارسی
print(render(rep, caption))                            # رسید: پنجره فید + چک‌ها
```

- **شغل A در برابر شغل B** را اول تصمیم بگیر: اگر ویدیو هوک کرده، کپشن
  درخواست + زمینه + کلیدواژه‌های جست‌وجو را می‌برد (شغل A)؛ اگر کپشن خودش
  محتوا است، خط اول هوک است (شغل B). این تصمیم اگر نگیرد کپشن با ویدیو
  رقابت می‌کند و هر دو می‌بازند.
- پنجره فید ۱۲۵ نویسه است؛ تقریباً هر کپشنی شکست می‌خورد، همان‌جا می‌خورد.
- سقف هشتگ ۵ است (از ۱۴۰۴/۰۹/۲۷ — ۱۸ Dec 2025)؛ هشتگ ZWNJ-دار می‌شکند
  (`#می‌خوره` روی پلتفرم یعنی `#می`). عبارت جست‌وجو را داخل متن بنویس.
- یک درخواست. دو درخواست یعنی هیچ.

### ۲. کاروسل (fa-instagram-carousel)

```python
from instagram import plan_carousel, audit_deck

slides = plan_carousel("موضوع", ["نکته ۱", "نکته ۲", "نکته ۳"], "فالو کن")
print(audit_deck(slides))
```

- ستون فقرات: اسلاید ۱ وعده+لوپ باز (نه عنوان خشک) → نکته‌های قوی اول
  → هر اسلاید یک ایده → پرداخت سیو-شدنی → یک CTA.
- هرگز پُر نکن: ایده‌ی ۵ نقطه‌ای = کاروسل ۷ اسلایدی.
- بودجه متن اسلاید با مدل عرض RTL سنجیده می‌شود؛ فارسی ۲۰–۳۵٪ باریک‌تر
  از لاتین رندر می‌شود — بودجه لاتین برای فارسی بیش‌ازحد محدودکننده است.

### ۳. هوک ریلز (fa-instagram-hook)

```python
from instagram import score_hook, classify_hook, get_formula

print(score_hook("این اشتباه دو سال از من گرفت تا بفهمم"))   # پنل ۵ ویژگی
print(classify_hook("هوکی که در طبیعت دیدی"))               # یا کناره‌گیری صادقانه
```

- ۱۲ فرمول فارسی (`FA01`–`FA12`) با میدان `trap` — هر فرمول خرابی مشهور
  خودش را مستند می‌کند.
- قواعد سختی‌ها: بدون سلام، بدون «در این ویدیو»، هشتگ و اموجی ممنوع در هوک.
- صداقت کالیبراسیون (از منبع): این پنل هوک‌های آشکارا ضعیف را می‌کشد
  (AUC≈0.83) ولی برنده‌ها را پیش‌بینی نمی‌کند (AUC≈0.56). «به گراف
  نگه‌داشتن مخاطب بیشتر اعتماد کن.»

### ۴. انسانی‌ساز (fa-instagram-human)

```python
from instagram import humanize, detect

out = humanize(draft)      # پاس‌های ۱–۳ خودکار؛ پاس ۴ فقط پرچم می‌زند
panel = detect(out["text"]) # پنل ۵ چک؛ ضعیف‌ترین ۴۰٪ وزن دارد
```

- پاس ۱: نویسه‌های نامرئی — **ZWNJ هرگز پاک نمی‌شود** (املاست، نه نویز).
- پاس ۲: خط‌تیره سقف دارد نه ممنوع (~۱ در ۱۰۰ واژه)؛ جایگزینی: ویرگول ←
  دونقطه ← پرانتز ← خط جدید ← بازنویسی، **هرگز نقطه**.
- پاس ۳: واژه‌نامه slop فارسی — جایگزینی اصطلاح‌محور، نه ترجمه تحت‌اللفظی.
- پاس ۴ (پرچم، نه بازنویسی): «نه فقط X، بلکه Y»، سه‌تایی انباشته، سوال
  بلاغی آغازین، یکنواختی طول جمله (CV < 0.35). بازنویسی ساختاری کار توست.

## ضدجعل (سخت و بدون استثنا)

عدد، اسم برند و نتیجه را **هرگز** از خودت نساز — حتی به‌عنوان جای‌نگهدار.
فرمول‌ها عدد می‌خواهند؛ اگر کاربر نداد، `{{عدد شما}}` را خالی بگذار و
پرچمش را بزن. «عدد ساخته‌شده = تکذیبنامه؛ عدد غایب = پست ضعیف‌تر.»

## خلاف‌های این مهارت (رد می‌شود)

- هوکی که معنایش در خط دوم است (برش فید می‌خوردش)
- اسلاید اول فقط عنوان؛ ۳ CTA رقیب در یک کپشن
- دیوار ۲۰–۳۰ هشتگی؛ «پک هشتگ وایرال»؛ تگ‌های بی‌ربط به محتوا
- درخواست‌های مشارکتی («کامنت YES»، «تگ ۳ رفیق») — پلتفرم جریمه می‌کند

## صفحه‌ی دروغ‌محورها (anti-pattern) و مرزهای صادقانه

- این پنل‌ها هیوریستیک محلی‌اند، نه GPTZero/Originality — ادعای «دور زدن
  تشخیص» ندارند.
- اعداد پلتفرم تاریخ‌دارند؛ اگر با رفتار فعلی اینستاگرام تناقض داشت،
  اینستاگرام درست است.
- هیچ ابزاری شبکه نمی‌رود، کلید ندارد و اطلاعاتی بالا نمی‌فرستد.
