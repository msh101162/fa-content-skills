# راهنمای توسعه — fa-content-skills

## قانون طلایی ۱: هیچ‌جا `\b` ننویس

`\b` پایتون روی فارسی خطا دارد (ZWNJ و اعراب `\w` نیستند). همیشه:

```python
from core.regex_patterns import whole_word

# بد:
re.search(r"\bمی\b", text)            # در «می‌خوره» هم match می‌کند!

# خوب:
whole_word("می").search(text)         # در «می‌خوره» match نمی‌کند
```

اگر کلاس نویسه تازه لازم داری، به `core/chars.py` اضافه کن — نه داخل
regex پراکنده. کلاس‌های بازه‌ای را با `_expand` گسترش بده تا عضویت
(`ch in X`) هم درست کار کند.

## قانون طلایی ۲: ZWNJ هرگز حذف نمی‌شود

- هیچ نرمال‌سازی‌ای نویسه‌ی `\u200c` را حذف/جایگزین نمی‌کند.
- NFKC امن است (ZWNJ نگاشت تجزیه ندارد) — ولی باز هم با تست محافظت کن.
- قرارداد تست: `zwnj_count(output) >= zwnj_count(input)`؛ تنها تغییر
  مجاز، **افزایش** از مسیر `zwnj_fix` است.
- هشتگ: ZWNJ داخل هشتگ **ممنوع** است (پلتفرم می‌شکند) — این استثنا در
  `hashtags()`/`broken_hashtags()` پیاده شده، نه با حذف نویسه.

## افزودن فرمول هوک (اینستاگرام)

۱. در `instagram/hooks.py` به `HOOKS` اضافه کن:

```python
HookFormula(
    "FA13", "اسم فارسی فرمول",
    "قالب با {{جای‌نگهدار}}",
    "مثال واقعی فارسی",
    "saves",                    # saves | shares | comments | follows
    "خرابی مشهور این فرمول در یک جمله",
    r"regex برای دسته‌بندی در طبیعت",   # ZWNJ-متحمل؛ بدون \b
)
```

۲. اگر فرمول باید در دسته‌بندی مشارکت کند، شناسه‌اش را به `CLASSIFY_ORDER`
اضافه کن (خاص‌ترین اول).
۳. تست اضافه کن: هم مثبت، هم کناره‌گیری (متن بدون فرمول → `None`).

## افزودن قاعده slop

دو نوع قاعده در `core/slop_lexicon.py`:

```python
# ۱. عبارت دقیق (با fa_phrase تا ZWNJ و فاصله متحمل باشد)
(fa_phrase("عبارت قالبی"), "عبارت", "medium", "جایگزین اصطلاح‌محور فارسی")

# ۲. آستانه‌ی استفاده مکرر
("بی‌نظیر", 0.3, "medium")   # بیش از ۰.۳ در هر ۱۰۰ واژه → پرچم
```

قواعد severity و جایگزین: `high` همیشه جریمه، `low` فقط با تراکم.
جایگزین‌ها **فارسی اصطلاح‌محور** باشند، نه ترجمه تحت‌اللفظی انگلیسی.

## افزودن پلتفرم جدید

۱. پوشه `platform/` با: `limits.py` (ثابت‌های تاریخ‌دار — هر عدد حساس
   به زمان، تاریخ منبعش را حمل می‌کند)، `SKILL.md` فارسی + `SKILL.en.md`.
۲. فقط سیاست پلتفرم را بنویس؛ سنجش/شمارش/عرض را از `core/` بگیر
   (~۷۰٪ منطق مشترک است).
۳. درِ تأیید در SKILL.md: «این مهارت می‌نویسد؛ تو منتشر می‌کنی.»
۴. در pyproject، بسته را به `[tool.setuptools.packages.find]` اضافه کن.

## افزودن وابستگی اختیاری

- فقط به‌صورت `[project.optional-dependencies]`؛ هسته stdlib خالص می‌ماند.
- نمونه: `render = ["pillow>=10.0"]` برای سنجش واقعی شکل‌دهی RTL با RAQM.
- در کد: import داخل تابع + پیام راهنمای نصب + fallback به مدل تخمین.

## تست‌ها

- هر قاعده فارسی تازه: مثبت + منفی + **گارد مثبت‌کاذب** (واژه واقعی که
  نباید دست بخورد — مثل «میان»، «بیدار»، «متر»).
- قراردادهای ثابت: `tests/test_normalizer.py` (ZWNJ invariant) را نشکن.
- اجرا: `pytest` — همه‌ی ۱۰۷ تست باید سبز بمانند.

## نسخه‌بندی

- PATCH برای محتوا/مستند؛ MINOR برای فرمول/قاعده تازه؛ MAJOR برای شکستن
  قراردادهای core (مثلاً تغییر schema خروجی lint).
- اعداد پلتفرم تاریخ‌دارند؛ هنگام تغییر، تاریخ تازه + منبع را در کامنت بگذار.
